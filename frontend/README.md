# TeamMatch 前端模块

> 本目录用于存放前端源码（成员A负责开发）。

## 前端技术栈

- HTML + CSS + Bootstrap
- JavaScript (jQuery)
- 对接后端 RESTful API（参见 `../docs/前端对接文档.md`）

## 页面清单

| 页面 | 文件 | 功能 |
|------|------|------|
| 登录页 | `login.html` | 学号密码登录 |
| 注册页 | `register.html` | 账号注册 |
| 系统首页 | `index.html` | 课程筛选 + 项目搜索 + 项目卡片 |
| 项目详情 | `project.html` | 项目信息 + 申请入组 |
| 发布项目 | `publish.html` | 发布新项目表单 |
| 组长审批 | `approval.html` | 待处理申请列表 + 审批操作 |
| 进度看板 | `progress.html` | 项目里程碑 + 状态更新 |
| 智能推荐 | `recommend.html` | 匹配度排序推荐列表 |
| 个人中心 | `profile.html` | 资料编辑 + 技能管理 |

## API Base URL
