## 三、安全审查

### 3.1 严重问题 (Critical)

#### C1. 密码使用MD5哈希存储

- **位置**：[server.py:14-15](server.py#L14-L15), [backend/service/UserService.php:107-109](backend/service/UserService.php#L107-L109)
- **问题**：两套后端均使用 `MD5(username + password + salt)` 存储密码
  ```python
  # server.py
  def hp(username, password):
      return hashlib.md5(f"{username}{password}{SALT}".encode()).hexdigest()
  ```
  ```php
  // UserService.php
  private function hashPassword($username, $password) {
      return md5($username . $password . PASSWORD_SALT);
  }
  ```
- **风险**：MD5已被证明不安全，可通过彩虹表快速破解。GPU可在秒级破解常见密码。
- **修复**：
  - Python: 使用 `bcrypt` 或 `hashlib.pbkdf2_hmac`
  - PHP: 使用 `password_hash($password, PASSWORD_BCRYPT)` + `password_verify()`

#### C2. 硬编码加密盐值

- **位置**：[server.py:11](server.py#L11), [backend/service/UserService.php:2](backend/service/UserService.php#L2)
- **问题**：SALT写死在源代码中，泄露代码即泄露盐值
- **修复**：
  - 使用环境变量 `SALT = os.environ.get('APP_SALT', 'default_dev_salt')`
  - 或使用 bcrypt（自动生成随机盐）

#### C3. CORS允许任意来源

- **位置**：[server.py:248](server.py#L248), [backend/util/Response.php:14](backend/util/Response.php#L14)
- **问题**：
  ```python
  self.send_header('Access-Control-Allow-Origin', '*')  # 允许所有来源
  ```
- **风险**：任何网站都可以向API发送跨域请求，可能被CSRF攻击利用
- **修复**：配置白名单域名
  ```python
  ALLOWED_ORIGINS = ['http://localhost:8080', 'https://your-production-domain.com']
  origin = self.headers.get('Origin', '')
  if origin in ALLOWED_ORIGINS:
      self.send_header('Access-Control-Allow-Origin', origin)
  ```

#### C4. Token/Session安全不足

- **位置**：[server.py:372-373](server.py#L372-L373), [backend/middleware/Auth.php:8-22](backend/middleware/Auth.php#L8-L22)
- **问题**：
  - Python: Token = `MD5(uid + timestamp)`，无过期时间，无HttpOnly标记
  - PHP: PHP原生Session，但前端用localStorage存用户数据
- **风险**：Token永不过期；XSS可窃取localStorage中的token
- **修复**：
  - Token设置过期时间（如24小时）
  - 敏感信息不应存在localStorage，考虑HttpOnly Cookie
  - 添加refresh token机制

#### C5. SQLite数据库文件可被直接下载

- **位置**：`_team_match.db` 在项目根目录
- **风险**：如果Web服务器配置不当，数据库文件可能被直接HTTP下载
- **修复**：将数据库文件移到Web根目录外，或添加 `.htaccess` 规则阻止访问

### 3.2 高优先级问题 (High)

| 编号 | 问题 | 位置 | 修复方案 |
|------|------|------|---------|
| H1 | 无登录速率限制 | `server.py:_login` | 添加基于IP的失败次数限制（5次/15分钟） |
| H2 | 无请求频率限制 | 全局 | 添加令牌桶或滑动窗口限流 |
| H3 | 无HTTPS支持 | 全局 | 生产环境必须配置TLS证书 |
| H4 | 密码最小长度仅6位 | `server.py:357` | 建议至少8位，含数字+字母+特殊字符 |
| H5 | 无CSRF Token | 全局 | 对状态变更请求添加CSRF Token验证 |
| H6 | 管理员接口无额外保护 | `server.py:571-631` | 添加二次验证或IP白名单 |

### 3.3 中优先级问题 (Medium)

| 编号 | 问题 | 修复方案 |
|------|------|---------|
| M1 | 前端localStorage存用户角色，可被篡改 | 角色判断以后端为准，前端仅用于UI展示 |
| M2 | 无Content-Security-Policy | 添加CSP头防止XSS |
| M3 | 无X-Frame-Options | 添加防止点击劫持 |
| M4 | 错误信息可能泄露内部细节 | 生产环境隐藏详细错误，仅返回通用信息 |
| M5 | 管理员seed密码为固定值 | 首次启动强制修改默认密码 |

### 3.4 安全总评


### 5.3 优化方案实施

#### 5.3.1 后端优化 — 解决N+1查询问题

**优化1：项目详情查询合并（server.py `_proj_detail`）**

将5次独立查询合并为2-3次批量查询：

```python
def _proj_detail(self, uid, role, pid, _):
    if self.command != 'GET': return self._json(405)
    
    # 查询1：主项目信息 + 课程 + 创建者
    p = db.d(db.execute("""SELECT p.*, c.cname AS course_name, c.teacher AS course_teacher,
        u.nickname AS creator_nickname FROM project p 
        JOIN course c ON p.cid=c.cid JOIN user u ON p.uid=u.uid
        WHERE p.pid=? AND p.is_deleted=0""", (pid,)).fetchone())
    if not p: return self._json(404, '项目不存在')
    
    # 查询2：批量获取 skills + members（并行）
    p['required_skills'] = db.ds(db.execute(
        "SELECT ps.sid,s.sname,s.category,ps.required_count FROM project_skill ps JOIN skill s ON ps.sid=s.sid WHERE ps.pid=?", (pid,)))
    p['members'] = db.ds(db.execute(
        "SELECT m.uid,u.nickname,u.avatar,m.role,m.join_time FROM member m JOIN user u ON m.uid=u.uid WHERE m.pid=?", (pid,)))
    
    # 构建响应
    p['current_members'] = len(p['members'])
    p['status_text'] = {0:'招募中',1:'已满',2:'进行中',3:'已结束'}.get(p['status'],'')
    p['course'] = {'cid':p['cid'],'cname':p['course_name'],'teacher':p['course_teacher']}
    p['creator'] = {'uid':p['uid'],'nickname':p['creator_nickname']}
    p['skills'] = [x['sname'] for x in p['required_skills']]  # 复用已查询数据
    
    if uid:
        a = db.execute("SELECT status FROM application WHERE pid=? AND uid=? ORDER BY aid DESC LIMIT 1", (pid,uid)).fetchone()
        p['my_application_status'] = a['status'] if a else None
    else:
        p['my_application_status'] = None
    
    self._json(200, 'success', p)
```

**优化2：项目列表技能批量查询**

不再对每个项目单独查询技能，改用一次JOIN批量查询：

```python
def _projects(self, uid, role, _, qs):
    # ... 筛选逻辑不变 ...
    rows = db.ds(db.execute(f"""
        SELECT p.pid,p.pname,p.description,p.max_members,p.status,p.deadline,p.created_at,
            (SELECT COUNT(*) FROM member m WHERE m.pid=p.pid) AS current_members,
            u.uid AS creator_uid,u.nickname AS creator_nickname,
            c.cid AS course_cid,c.cname AS course_cname
        FROM project p JOIN user u ON p.uid=u.uid JOIN course c ON p.cid=c.cid
        WHERE {ws} ORDER BY p.created_at DESC LIMIT ? OFFSET ?
    """, v+[ps,(pg-1)*ps]))
    
    # 批量获取所有项目的技能（一次查询替代N次查询）
    if rows:
        pids = tuple(r['pid'] for r in rows)
        placeholders = ','.join('?' * len(pids))
        skill_rows = db.ds(db.execute(
            f"SELECT ps.pid, s.sname FROM project_skill ps JOIN skill s ON ps.sid=s.sid WHERE ps.pid IN ({placeholders})", pids))
        
        # 建立 pid -> skills 映射
        skill_map = {}
        for sr in skill_rows:
            skill_map.setdefault(sr['pid'], []).append(sr['sname'])
        for r in rows:
            r['skills'] = skill_map.get(r['pid'], [])
    
    self._json(200, 'success', {'list':rows,'total':total,'page':pg,'page_size':ps})
```

## 十、环境配置管理

### 10.1 问题

| 问题 | 影响 |
|------|------|
| 配置硬编码在源码中 | 切换环境需改代码 |
| 密码/盐值写在代码里 | 安全风险 |
| 无 `.env` 文件支持 | 无法区分dev/staging/prod |
| 数据库每次启动重建 | 数据不持久 |

### 10.2 改进方案

```python
# config.py
import os
from dotenv import load_dotenv

load_dotenv()

class Config:
    DEBUG = os.getenv('DEBUG', 'false').lower() == 'true'
    DB_PATH = os.getenv('DB_PATH', '_data/team_match.db')
    SALT = os.getenv('APP_SALT', 'change_me_in_production')
    PORT = int(os.getenv('PORT', '8080'))
    RESET_DB_ON_START = os.getenv('RESET_DB', 'false').lower() == 'true'
```

对应 `.env.example` 文件模板：

```ini
DEBUG=false
DB_PATH=_data/team_match.db
APP_SALT=change_me_in_production
PORT=8080
RESET_DB=false
```
